# 自动收集结果（可选）

默认情况下，参与者做完后会下载一个结果文件，再发给你。这一步是可选的：设置好以后，结果会**自动保存到你的 Google Drive**，参与者不用再发文件。

> 注意：中国大陆访问不了 Google。那边的参与者会看到"自动提交没有成功"，页面会提示他们把下载的文件发给你，不影响实验。

## 设置步骤（约 10 分钟，只做一次）

1. 用你的 Google 账号打开 <https://script.google.com>，点左上角 **新项目**。
2. 删掉编辑器里原有的代码，把本文件夹里 `apps_script.gs` 的全部内容复制进去，点 **保存**（项目名随便起，例如 image study）。
3. 点右上角 **部署 → 新建部署**。点"选择类型"旁边的齿轮，选 **网页应用**，然后：
   - 说明：随便写
   - 执行身份：**我**
   - 谁可以访问：**任何人**
4. 点 **部署**。第一次会要求授权：选你的账号 → 出现"Google 尚未验证此应用"时点 **高级 → 转至 image study（不安全）** → **允许**。这个脚本是你自己的，只会往你自己的 Drive 写文件。
5. 复制显示的 **网页应用网址**（以 `https://script.google.com/macros/s/` 开头、以 `/exec` 结尾）。
6. 在浏览器里打开这个网址，看到 `ok: the collection address works` 就说明能用。
7. 打开网站文件夹里的 `config.js`，把网址填到 `upload_url: ''` 的引号里，保存，然后推送（见 `组织者说明.md` 第 3 步）。
8. 自己用一个编号完整做一遍，确认你的 Google Drive 里出现了文件夹 `image_study_results` 和一个 `.json` 文件。

## 收到的文件

- 每做完一份，`image_study_results` 里就多一个 `image_study_P05_….json`。
- 把这些文件下载下来，和参与者发给你的文件放在一起（研究文件夹的 `subj_own_results/`）。同一份结果可能既自动提交、又被参与者发来，重复的没关系，检查脚本会标出来。
